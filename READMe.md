# 세계 친구 여권

아이들이 세계 30개 나라의 유명 인물을 보고 그 사람의 나라를 맞히는 게임이에요.

- 공유 주소: https://world-friends-passport.vercel.app
- 10문제 도전 또는 30개 나라 모두 도전 중에서 고를 수 있어요.
- 문제마다 기회는 두 번이에요.
- 맞히면 여권에 그 나라 도장이 찍혀요.
- '인물 사진 넣기'에서 사진을 넣을 수 있어요. 사진은 그 기기의 브라우저에만 저장돼요.

## 파일

- `index.html` : 게임 전체(HTML, CSS, JavaScript가 한 파일에 들어 있어요)

## 인물 추가·수정

`index.html`에서 `const PEOPLE = [` 부분을 찾아 한 줄씩 추가하거나 고치면 돼요.

```js
{ id:"kr", country:"대한민국", flag:"🇰🇷", name:"손흥민", job:"축구 선수", emo:"⚽", fact:"설명 문장" },
```

`id`는 나라마다 겹치지 않는 짧은 영문으로 적어 주세요.
